# 추천 시술 증상별 분류

자료 확인일: 2026-11-10. 제조사·의학회·의료기관의 공개 자료를 대조한 **사이트 탐색용 편집 분류**입니다. 허가 범위의 통일이나 환자별 적응증 확정을 의미하지 않습니다. 제조사 설명과 의료기관 활용 사례는 근거 수준이 다르며, 장비 모드·제품·국가에 따른 차이를 유지합니다.

## 적용 원칙

- 활동성 여드름과 여드름 흉터를 별도 분류합니다. 흉터 시술을 여드름 점수에 자동 연결하지 않습니다.
- 주된 목적 → 함께 검토할 목적 → 조건 확인이 필요한 활용 순서로 표시합니다. 각 필터는 중복 카드 없이 시술 수를 표시합니다.
- 조건부 활용과 상담 전용 항목은 자동 추천 대상에서 제외합니다. 모든 항목은 전체 목록에서 계속 볼 수 있습니다.
- 홍조는 원인 진단과 장비 모드 확인을 우선합니다. 포텐자의 제조사 자료에 주사/홍조 활용이 있으므로 조건부 탐색에만 포함합니다.
- 얼굴 좌우 균형 점수를 턱·측두근·입꼬리·귀밑샘 보톡스 또는 윤곽주사에 연결하지 않습니다. 좌우 균형 필터는 원인 확인 안내를 표시합니다.
- 수분·피부결과 윤곽 등은 현재 사진 분석이 직접 측정하지 않는 탐색 분류입니다.

## 원문과 확인 정보가 달랐던 항목

- 셀르디엠: 제조사는 hADM 인체조직으로 설명합니다. CSV의 줄기세포 배양액 설명을 추천 카드에 사용하지 않습니다.
- 리쥬란: 일반 제품은 PN으로 분류합니다. 통칭 PDRN 연어주사와 같은 제품으로 가정하지 않습니다.
- 올리디아: 제조사의 PLLA 정보를 적용합니다. CSV의 HA 설명을 근거로 수분 시술에 연결하지 않으며 세부 제품 확인 대상으로 둡니다.
- 릴리이드 M: 릴리이드와 별도 제품이므로 이름이 비슷하다는 이유로 같은 용도를 적용하지 않습니다.
- 큐어젯·약물 전달기기: 전달 수단 자체를 독립적인 치료 성분·효능으로 해석하지 않습니다.

이번 수정은 추천 페이지 분류·카드 요약·추천 순서에 적용됩니다. 원본 CSV와 기존 상세 설명·FAQ·가격 원문은 변경하지 않았습니다. 원문 전체의 임상 내용 재검토는 이 분류 작업과 별도입니다.

## 코드와 검증

- `src/data/treatmentClassification.json`: 30개 항목의 분류·추천 연결·짧은 설명·출처. 다음 CSV 재수입에서도 이 파일을 기준으로 분류합니다.
- `src/data/treatmentConcerns.ts`: 필터, 주된 목적/관련/조건부 순서.
- `src/analysis/treatmentRecommendations.ts`: 검토한 연결만 이용하는 정렬과 관련 배지.
- `src/i18n/treatmentConcerns.ts`: 한국어·영어·일본어·중국어 필터와 안내.
- `npm test`: 분류 및 추천 규칙 6개, 기존 화면·가입 흐름 6개.
